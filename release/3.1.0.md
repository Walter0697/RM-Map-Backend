# RoroadMap 3.1.0 — Quality of Life Improvements

release-note-image

We’re excited to introduce RoroadMap 3.1.0, focused on making everyday planning faster and easier with a new direct Shortcut workflow, clearer analysis status, and a smoother review experience.

release-note-image

## 📱 Direct Shortcut Workflow

- **Roroadmap Analyze Shortcut:** Send a supported post URL directly from iOS Shortcuts without going through Telegram.
- **One-time account setup:** Configure the Shortcut once so it remembers the RoroadMap domain and account API key.
- **Shortcut management:** Download, configure, and manage the Analyze Shortcut from Settings.

## 🧠 Social Post Analysis

- **Automatic post analysis:** Analyze social media URLs and extract useful location information for a new marker.
- **Image-aware analysis:** Use available post images as part of the analysis when the source provides them.
- **Smarter marker output:** Use the supported marker type list so generated markers fit the application’s existing categories.

## ⏳ Pending Analysis Review

- **Pending marker status:** Posts that need confirmation are clearly separated from completed markers.
- **Home-screen notification:** See when analysis results are waiting for review.
- **Detail review flow:** Open a pending item, inspect its information, and decide whether to keep it.

## 🔐 API Key Management

- **Shortcut API keys:** See API keys created for your installed Shortcut integrations.
- **Revoke access:** Revoke an individual Shortcut key directly from Settings when it is no longer needed.

## 🛠️ Reliability Improvements

- Improved Shortcut setup behavior when the browser hands off to the iOS Shortcuts app.
- Added clearer analysis progress states so submitted requests are easier to understand.
- Improved handling of source images and analysis metadata.

The release-note images can be uploaded from **Admin → Release Notes**, then inserted into this content before publishing the `3.1.0` note.
